# Changelog

## 0.1.0 — 2026-11-04

Initial package release as `meteora-rag`, imported as `meteora_rag`.

- Rationale-driven evidence selection with pairing, statistical elbow pooling,
  and neighboring chunk expansion.
- Reranker-compatible filtering with selection and verification diagnostics.
- Hugging Face rationale generation with optional verifier flag instructions.
- Model-independent verification and structured rejection decisions.
- DPO preference data preparation and optional Hugging Face training support.
- Text chunking, selection metrics, and the `meteora-rag` command-line interface.
- Optional dependencies for SentenceTransformers, generation, and training.
- CC BY 4.0 licensing, build validation, and GitHub Actions trusted publishing.
