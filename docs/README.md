# METEORA Project Website

This directory contains the static GitHub Pages site for METEORA.

## Publish On GitHub Pages

1. Commit the `docs/` directory.
2. Open the repository on GitHub.
3. Go to Settings, then Pages.
4. Set the source to deploy from a branch.
5. Select `main` and `/docs`.
6. Save.

The expected URL is:

```text
https://yashsaxena21.github.io/METEORA/
```

No build step is required.
